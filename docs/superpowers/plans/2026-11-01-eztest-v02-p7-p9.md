## Review Focus（最可能出问题的五类输入/条件）

1. **GC 边界对象**：仍在宽限期、被旧报告 revision 引用、跨上下文 owner 已删（悬空 ref）、对象被多个 ref 共享时，GC 必须不删或只删精确候选；测试须覆盖“受保护对象 + 共享对象 + 悬空 ref”同时存在的一轮 apply。
2. **PDF 元数据不可变**：PDF 生成/重试/失败更新后，`as_of`、`html_ref`、`input_fingerprint`、`template_version`、HTML 字节必须完全不变；测试须在 PDF done/failed 后逐列断言。
3. **多副本重复执行/重复迁移**：两个 API 副本同时跑 reconciler/scheduler/poller/GC 时，不得产生重复 case_run/agent_run、不得批量中断 running、迁移只执行一次；测试须用双进程真实 PG 断言计数。
4. **复发重定向与旧报告**：合并 A→B 后同 dedupe_key 复发必须只落 B（A 的 refs/历史不变、不重开），且旧 revision 的 HTML/统计不变；测试须同时断言 A、B、旧 revision 三者。
5. **知识注入边界**：draft/rejected/revoked、`source_stale`、scope=system 不匹配、超预算/超条数时必须不注入或截断，且响应/上下文不泄露未审核内容；测试须覆盖每种状态各一条。
