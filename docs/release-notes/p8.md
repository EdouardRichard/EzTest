## 2. 升级前必读

### 2.1 报告指纹一次性 stale

P8 扩展了报告 `input_fingerprint`：除既有批次/用例/问题计数外，纳入每个用例最新 attempt 的 `evidenceCount` 与批次失败分类计数。升级后**已发布的旧报告在第一次读取时会因指纹口径变化被标记 stale 一次**：

- 旧 revision 的快照内容与 Markdown 字节不重写；
- 只发布一次 `report.stale`（`detail.reason=input_fingerprint_changed`）；
- 重新生成会追加 revision（`max+1`），不会覆盖历史；
- 这是有意的行为变化，不是数据损坏。

### 2.2 迁移 append-only

- P8 只追加迁移：`codeintel_0006_version_change.sql`、`codeintel_0007_fact_review.sql`、`version_0006_knowledge.sql`、`quality_0001_eval.sql`、`execution_0004_evidence_purge.sql`、`mindmap_0003_visual.sql`、`execution_0005_visual_evidence.sql`（视觉迁移已提交并在启动时执行；视觉 API/执行入口已接线）。
- **不要修改已应用的历史迁移**；`schema_migrations` 校验和不匹配会导致启动失败。升级前备份，回退用备份恢复，不写 down migration。
- 启动时自动迁移，无需手工 migrate 命令；多实例滚动时每个实例都会在 advisory lock 下等待/执行。

### 2.3 `.env` 与目录

- Compose 新增持久化卷：`evidence`、`reports`、`exports`（连同已有的 `objects`、`attachments`、`pgdata`）；`Dockerfile.api` 会创建并 chown 这些目录。
- P8 新增/使用环境变量：`EZTEST_RATE_LIMIT_RPS/BURST/SSE_MAX`、`EZTEST_GC_ENABLED/RETENTION_DAYS/BATCH_KEEP`、`EZTEST_INSTANCE_ID`、`EZTEST_LEADER_LOCK_KEY`、`EZTEST_KNOWLEDGE_MAX_INJECT/MAX_BYTES`、`EZTEST_VISUAL_BASELINE_MAX_BYTES`（**已接线**：API + executor，默认 5242880，64 KiB–20 MiB）；`EZTEST_VISUAL_DIFF_THRESHOLD` 为**预留**（未读取，阈值按断言配置）。
- P8 执行器硬化：`EZTEST_EXEC_MAX_TOOL_CALLS` 默认改为 **30**、范围 **1–200**（原默认 80/1–1000），耗尽以 `inconclusive(model, tool_call_budget_exhausted)` 结束；新增 `EZTEST_EXEC_ALLOWED_HOSTS`（executor 的 WS host 白名单，默认 `localhost,127.0.0.1`，远程目标需显式配置；WS 仍须通过 context `allowedHosts`，HTTP 导航/请求不受影响）。
- P7 配置已在 P8 接线：`EZTEST_ANALYSIS_MAX_CASES` 1–50（默认 20）、`EZTEST_SUPPLEMENT_MAX_CASES` 1–20（默认 5）、`EZTEST_AUTONOMY_BATCHES_PER_TICK` 1–20（默认 4；>20 钳制为 20，<1/非整数启动失败）。
- 规格中的 `EZTEST_CHAIN_MAX_NODES`、`EZTEST_SEARCH_MAX_RESULTS_PER_TYPE`、`EZTEST_TODOS_MAX` **当前未接线**，不要依赖；`EZTEST_VISUAL_DIFF_THRESHOLD` 同样未读取。
- 备份不包含 `.env`/`EZTEST_SECRET_KEYS`；keyring 丢失则已加密 LLM Key/headers 不可恢复（见运维手册）。

## 3. 行为变化

### 3.1 API / 事件

| 变化 | 说明 |
|---|---|
| `GET /api/versions/{id}/exploration-chain` | 新只读聚合端点；服务端完成最新 attempt/问题/证据计数/覆盖/影响面/预算截断。`Cache-Control: no-store`。 |
| `GET /api/search` | 版本/需求/用例/问题分组；`q` 1–100 字符，per-type `limit` 1–20（默认 5）；单 Provider 失败降级为 `degraded=true`。 |
| `GET /api/todos` | review 全员可见；takeover/gate 仅管理员；`limit` 1–200（默认 50）。 |
| `/api/agent-center/{catalog,sessions,quality}` | 登录只读；13 角色；未知 role/status 422；不返回 prompt/transcript。 |
| `/api/versions/{id}/knowledge`、`/api/knowledge` | 草稿创建/编辑、admin 审核、全局已批准；revision CAS；注入预算；事件只含 ID/状态。 |
| `/api/code/repos/{repoId}/quality`、`.../facts/{factId}/reviews` | 代码质量聚合与人工事实修正；修正按 repo/fact/commit upsert。 |
| `/api/quality/eval-runs` | admin；确定性/真实 LLM 两条轨道；服务端派生指标，调用方不能只凭 status 声称通过。 |
| `POST /api/admin/gc` | admin；默认 dry-run；`EZTEST_GC_ENABLED=false` 时非 dry-run 409；单次候选上限 10000。 |
| `GET /api/versions/{id}/code/changes` | 增加 `batchTimeline`（`version_change` 快照；provisional/unavailable 标记）。 |
| `PUT /api/versions/{versionId}/mindmap/assertions/{assertionId}/visual` | 登录用户配置 visual 断言的 selector/region/threshold/viewport/DPR（节点 revision OCC）。 |
| `POST .../visual/baseline` | admin 审批 PNG 基线（screenshot/visual_baseline；sha256/大小/尺寸校验；`EZTEST_VISUAL_BASELINE_MAX_BYTES`）。 |
| `GET /api/health` | 增加 `rate_limit`（rps/burst/sse_max）与 `gc`（enabled/retention_days/batch_keep）只读投影。 |
| 事件 | 新增 `knowledge.created`/`knowledge.reviewed`/`case.visual_baseline_approved`；`code.changed` 由快照/分析发布；`report.stale` 带 reason；detail 只含 ID/状态/计数，不含基线图片字节。 |
| OpenAPI | 版本 `0.9.0`；新增 P8 paths/schemas/错误/事件，含两条 visual path、`visual` 断言字段、三类 visual evidence kind 与 `case.visual_baseline_approved`。 |

### 3.2 前端

- 版本详情固定 10 Tab：需求与澄清、用例脑图、总览、执行会话、探索链路、实时播报、结果与证据、问题、报告、代码与变更；`?tab=mindmap&case=` 与全屏路由共享组件。
- 顶栏：版本切换器（最近 8 个+搜索）、全局搜索（`Ctrl/Cmd+K` 或 `/`）、待办铃铛（30s 轮询）、移动端抽屉导航。
- 探索链路：React Flow 画布，MiniMap/图例/Sheet/跟随/截断横幅/空错重连；自有 ARIA/键盘。
- `/knowledge`：全局已批准 + 管理员审核抽屉（`?review=`）；版本概览内提交草稿。
- `/quality`：admin 评测看板（指标/阈值/历史）。
- 报告 Tab：revision 选择器、D49 回退标记、stale 重新生成。
- 视觉断言（D62）：CaseEditor 配置 selector/region/threshold/viewport/DPR；管理员从证据审批基线；EvidenceViewer 展示 `visual_baseline`/`visual_actual`/`visual_diff` 并支持并排对比。
- Agent 中心：普通用户只读角色目录/运行观察/质量指标；管理员保留配置与控制台。

### 3.3 非功能

- 限流：429 `rate_limited` + `Retry-After`；SSE 并发单独计数；健康检查/静态资源/OpenAPI 豁免；**按实例内存计数**。
- 执行器：工具调用预算实际强制（默认 30，1–200；超限 `inconclusive(model, tool_call_budget_exhausted)`）；WS 默认只允许 loopback（`EZTEST_EXEC_ALLOWED_HOSTS`，同时受 context `allowedHosts` 约束，HTTP 导航/请求不受影响）；后台硬超时以 `inconclusive(model, executor_timeout)` 收尾并取消/重建 page。
- GC：默认 dry-run；只清 `EZTEST_EVIDENCE_DIR` 下证据；保护最近 N 批/运行中/未关闭问题/视觉基线/已清除行；删除前复核；审计 best-effort。
- 备份：`pg_dump -Fc` + 五目录 tar + manifest（sha256/行数/配置键名）；恢复拒绝非空目标与危险库名；不含密钥。
- 多实例：调度/自主 worker/每日维护各用派生 advisory lock key；SSE/Agent runner 仍进程内。
- 安全：Next 安全头（CSP report-only）、审计查看器筛选/导出、秘密/依赖/权限审计脚本。
